# Dugout Atlas v1.92

- 심화 비교에서 현재 로드된 선수별 시즌·지표·Statcast 백분위를 UTF-8 CSV로 저장할 수 있습니다. 결측값은 빈칸입니다.
- 홈 즐겨찾기에서 선수 이름이나 팀 약칭으로 검색하고 선택 시즌의 선수 분석을 열 수 있습니다.
- 타자 추이에서 시즌 선택기를 기간 선택 옆에 상시 표시합니다.
- 연도별·월별·일별 WAR / wRC+ 조회가 선택 시즌을 기준으로 동작합니다.
- 투수 페이지의 시즌 선택은 좌·우 타자 상대 성적(Platoon Splits)에도 적용됩니다.
- 월별 시즌 선택 전용 안내 문구를 모든 기간의 시즌 선택 안내로 정리했습니다.
