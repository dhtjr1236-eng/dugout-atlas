# Dugout Atlas v1.2

## 검색 기능 보강

- 이름의 앞부분뿐 아니라 성/중간 문자열로도 선수를 찾을 수 있도록 자동완성을 보강했습니다.
- 예: `Yusei Kikuchi`는 `Yusei`뿐 아니라 `Kikuchi`로도 검색할 수 있습니다.
- 메인 검색창과 Compare 검색창 모두 부분 문자열 매칭을 사용합니다.
- MLB 기본 검색이 부분 이름을 놓치면 현재 시즌 MLB 선수 목록을 이용한 보조 검색을 시도합니다.

## 시즌 선택

- 선수 이름 오른쪽에 시즌 선택 드롭다운을 추가했습니다.
- 현재 시즌 기록이 있으면 현재 시즌을 기본 선택하고, 없으면 해당 선수의 가장 최근 MLB 시즌을 선택합니다.
- 시즌 변경 시 선수 페이지의 기본 기록, FanGraphs/B-Ref, Statcast, Running, Platoon Splits와 관련 차트를 선택 시즌 기준으로 다시 불러옵니다.

## Platoon Splits

- 타자는 Running 아래에, 투수는 Statcast 영역 아래 흐름에 `Platoon Splits` 박스를 표시합니다.
- AVG / OBP / SLG / OPS / wRC+를 좌우 상대별로 표시합니다.
- FanGraphs split 데이터를 우선 사용하고 slash line이 비어 있으면 MLB Stats API `statSplits`로 보완합니다.
- 투수 상대 wRC+는 제공처가 실제 값을 반환하는 경우에만 표시하며 임의로 합성하지 않습니다.

## 라이브 득점 플레이

- Gameday의 Linescore 표 아래에 `득점 플레이` 표를 추가했습니다.
- 각 득점 플레이마다 이닝, 실제 득점자 이름, 득점 유형, 타점 수, MLB play-by-play 설명을 표시합니다.
- 홈런은 `HR`, 2루타는 `2B`, 3루타는 `3B`, 안타는 `1B`, 희생플라이는 `SF`, 볼넷은 `BB`, 폭투는 `WP` 등으로 표시합니다.
- 한 플레이에서 여러 명이 득점하면 실제 score로 이동한 주자 이름을 함께 표시합니다.
- 타점이 없는 폭투/실책 등의 득점도 실제 득점 주자가 있으면 표시합니다.
