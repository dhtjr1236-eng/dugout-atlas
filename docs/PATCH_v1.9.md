# Dugout Atlas v1.9

- Windows 설치 마법사: 한국어·영어, 설치 위치·바로가기 선택, 설치 후 실행.
- 실행 파일·설치 파일·앱 버전 표기를 1.9로 통일.
- Advanced Compare에서 선수별 시즌 선택, 같은 시즌의 A·B·C 최대 3인 Season Race 지원.
- 비교 선수 선택 해제와 지연 응답 무효화.
- 선수·시즌 전환 시 이전 응답과 이전 시즌 차트의 혼입 방지.
- 사이드바 접기·펼치기와 화면 효과 줄이기 전환 오류 수정.
- Neon HUD, 라이트·다크 테마, MLB 선수 프로필 사진.

설치 파일과 해당 빌드 소스 ZIP을 함께 제공합니다.
기존 소스 실행의 데이터는 자동 이관하지 않습니다.
실제 통계 제공처의 접근·응답 상태에 따라 일부 값이나 사진이 없을 수 있습니다.
