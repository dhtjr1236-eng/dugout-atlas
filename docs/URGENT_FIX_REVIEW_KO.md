# 배포 전 긴급 수정 검토

아래 항목은 로컬 개발 소스에 적용한 수정입니다. 기존 `release/DugoutAtlas-Setup.exe`는
수정 전 빌드이므로 이 패치를 포함한 새 설치본으로 간주하면 안 됩니다.
공개 main 소개 개편과 v1.9 Release 게시는 별도 검토 대상입니다.

## 수정한 문제

1. **선수·시즌 응답 순서:** 실제 시작 과정에서 설치되는 시즌 선택 확장 로더가
   기본 컨트롤러의 요청 세대 검사를 우회했습니다. 빠르게 같은 선수의 시즌을
   바꾸거나 A→B→A로 이동할 때 이전 성공·실패 응답이 최신 상태를 건드리지 않도록
   세대와 요청 키를 검사합니다. 조회 중에도 다른 시즌을 선택할 수 있습니다.
   명시적으로 고른 시즌을 시즌 목록에 없다는 이유로 다른 해로 바꾸지 않습니다.
   선택 시즌과 분석 컨텍스트를 일치시키며 투수 변화 분석도 해당 시즌으로 초기화합니다.

2. **이전 시즌 그래프 혼입:** 타자 추이와 투수 Statcast 구간 조회에도 요청 세대를
   검사합니다. 이전 시즌의 월별 응답이 늦게 와도 새 화면에 적용하지 않고,
   새 시즌에서 요청한 같은 월별·일별 구간은 다시 조회합니다.

3. **3인 비교 복귀:** Advanced Compare 각 슬롯에 `선수 선택 해제` 버튼을 추가했습니다.
   C를 비우면 A·B의 2인 레이스로 돌아갑니다. 선택 해제 전 시작된 응답이 늦게 와도
   슬롯을 다시 채우지 못하게 무효화합니다. 새 조회에서 이전 실패 툴팁도 제거합니다.
   버튼 문구는 한국어·영어·일본어를 지원합니다.

4. **사이드바 애니메이션 종료 참조:** 접기 애니메이션 도중 `화면 효과 줄이기`를
   활성화하면 다음 접기에서 삭제된 QVariantAnimation을 참조하는 RuntimeError가
   발생했습니다. 삭제 예약 후 참조를 즉시 비워 재사용하지 않도록 수정했습니다.
   회귀 테스트로 수정 전 오류와 수정 후 정상 동작을 확인했습니다.

## 검증 범위

통신 응답의 순서를 직접 제어하는 테스트, 같은 선수의 시즌 전환, 이전 실패 응답,
같은 구간 재조회, C 선택 해제 후 지연 응답, 애니메이션 중 효과 줄이기 전환을 검사합니다.
테스트는 프로젝트 `.venv`로 실행하며 실제 MLB·FanGraphs 서버의 응답 상태를
보증하지 않습니다. 신규 설치본 제작·업로드 결과는 이 문서에 포함하지 않습니다.
