# Dugout Atlas v1.5.2 — 사용자 지정 선수명·기본 창 크기

## 변경사항

- 사용자가 지정한 101명의 영어·일본어·한국어 표기를 그대로 반영했습니다.
- 기존 24명 목록과 병합하여 총 113명의 표시 사전을 유지합니다. 겹치는 12명은 새 표기로 갱신하며, 나머지 기존 선수는 유지합니다.
- 새 101명은 자동 수집/가타카나 변환/기존 캐시보다 사용자 표기를 우선합니다. 이정후의 일본어는 `李政厚`입니다.
- 예전 표기와 악센트 없는 영어 표기를 검색 별칭으로 유지합니다. José/Jose, Ramírez/Ramirez 등의 차이를 정규화합니다.
- 한·일 선수명 검색은 기존 영어 검색 및 MLBAM ID 선택 흐름을 사용합니다. 이름 사전은 표시와 검색 별칭용이며 동명이인 통계를 합치거나 선수 ID를 변경하지 않습니다.
- 시즌 레이스의 제목·범례·tooltip과 심화 비교 자동완성에도 표시 사전을 연결했습니다.
- 메인 창: 1440×900 → **1296×810**. 심화 비교: 1500×900 → **1350×810**. 각 가로·세로를 90%로 줄였습니다.
- 화면 작업 영역이 더 작으면 너비 32px, 높이 64px 여유를 두고 추가 축소합니다. 내부 내용의 최소 크기로 창이 다시 커지는 문제는 스크롤 영역으로 방지합니다. 글자 크기 자체는 변경하지 않습니다.

## 적용

이번 ZIP은 **v1.5 또는 앞서 제공한 v1.5.1 패치 상태에 적용 가능한 누적 패치**입니다. 시즌 레이스 변경도 포함합니다.
압축을 프로젝트 밖에 풀고 앱을 종료한 뒤 실행하세요.

```powershell
py -3 apply_patch.py --target "C:\Apps\dugout-atlas" --check
py -3 apply_patch.py --target "C:\Apps\dugout-atlas"
```

또는 `apply_patch.bat`을 실행하고 프로젝트 폴더를 입력합니다.
기존 파일이 v1.5/v1.5.1의 알려진 내용과 다르면 덮어쓰지 않고 중단합니다.
실제 적용 시 자동 생성되는 `season-race-backup-...` 경로를 보관하세요.

```powershell
py -3 apply_patch.py --target "C:\Apps\dugout-atlas" --rollback "C:\Apps\dugout-atlas\season-race-backup-시간값"
```

복구는 적용 직전 상태(v1.5 또는 v1.5.1)로 되돌립니다. 데이터베이스·사용자 설정은 수정하지 않습니다.
ZIP의 `dugout_atlas_1.5.2.patch`는 **원본 v1.5 기준** Git diff입니다. v1.5.1에는 위 적용기를 사용하세요.

적용 후 앱을 완전히 다시 실행해야 메모리에 로딩된 선수명 사전이 갱신됩니다. 기존 이름 캐시 파일은 삭제할 필요가 없습니다.

## 확인 방법

1. Settings에서 한국어·일본어·영어를 바꾸고 Aaron Judge, Jung Hoo Lee, José Ramírez를 검색합니다.
2. 한국어 `애런 저지`, 일본어 `李政厚`, 악센트 없는 `Jose Ramirez`로도 검색을 확인합니다.
3. 심화 비교와 시즌 레이스에 동일한 표기가 나타나는지 확인합니다.
4. 작은 화면에서는 창 전체가 작업 영역에 들어가고, 필요한 경우 내부 스크롤로 모든 버튼에 접근할 수 있습니다.

## 검증 및 범위

- 101명 × 3개 언어 = 303개 표기가 입력 목록과 정확히 일치함을 확인했습니다.
- 101명의 한국어·일본어 검색 별칭, 오래된 캐시보다 사용자 표기가 우선함, 악센트 정규화를 확인했습니다.
- 기존 133개 테스트 통과. CJK 글꼴이 없는 Linux 환경의 기존 경고는 남아 있습니다.
- 1920×1080 작업 영역의 90% 기본 크기 계산, 실제 Qt 800×800 환경에서 두 창이 768×736으로 제한되는 것을 확인했습니다.
- 패치 적용/재적용/복구는 원본 v1.5와 이전 v1.5.1 양쪽 기준에서 확인합니다.
- Windows 11 네이티브 화면과 CJK 글꼴 렌더링은 별도 확인이 필요합니다.
- 원격 commit/push/merge/release 없음. 이전 시즌 레이스의 데이터 의미·날짜 제약은 `docs/SEASON_RACE_GUIDE_KO.md`를 참고하세요.
