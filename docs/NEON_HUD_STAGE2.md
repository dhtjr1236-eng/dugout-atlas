# Neon HUD — 2단계

## 선수 화면

- 공통 HUD 패널에 프로필 실루엣·선수명·기존 시즌 선택·요약 카드 네 개를 배치합니다.
- 넓은 영역은 프로필/요약을 나란히, 좁은 영역은 세로로 재배치합니다.
- 추이·투구 차트를 핵심 지표 바로 다음에 표시하고 기존 상세 지표와 출처는 아래에 유지합니다.
- 프로필 실루엣은 사진 대체 이미지이며 실제 선수 사진을 생성하거나 추가 다운로드하지 않습니다.
- 시즌 선택 확장 코드는 프로필 영역의 이름 행에 연결합니다. 기존 기간 값·controller·Signal 계약은 유지합니다.

## Advanced Compare

- 선수 2~4명의 선택 시즌과 정확한 원래 수치를 유지합니다.
- 비교 막대는 각 행의 공통 범위에서 0을 기준으로 그립니다. 종합 점수나 우열을 뜻하지 않습니다. 결측값에는 막대를 그리지 않습니다.
- 백분위 막대는 0~100 고정 범위이며, 각 선수의 선택 시즌 분포를 사용합니다.
- 레이더는 모든 선택 선수에게 공통으로 있는 유한한 백분위가 3개 이상일 때만 그립니다. 축 이름은 실제 지표이며 Power/Contact 등의 가상 종합 점수를 만들지 않습니다.
- 비교 테이블은 수정 불가능한 읽기 전용 표시입니다. 작은 창에서는 선택 영역과 분석 패널이 재배치됩니다.
- A/B 시즌이 다르면 기존처럼 Season Race 탭이 비활성화됩니다.

## 검증과 미리보기

전체 회귀 테스트와 별도로 음수·결측·선수별 시즌·4인 비교·3개 언어 프로필 배치 테스트를 제공합니다.

```powershell
.\.venv\Scripts\python.exe tools/preview_hud_stage2.py --output output/neon-stage2
```

미리보기는 실제 화면과 예시 선수/예시 분포만 사용하고 외부 데이터를 요청하지 않습니다. 레이스 및 영상 내보내기의 HUD 스타일은 3단계 승인 후 적용합니다.
