# Dugout Atlas v1.8 — OPS 레이스와 움직이는 결과물

반영일: 2026-10-11. v1.7 기반 OPS·축 범위·애니메이션 검토 패치를 통합합니다.

## 바뀐 기능

- **OPS · MLB**: 정규시즌 두 타자의 경기별 H/BB/HBP/AB/SF/TB를 합산해 OBP + SLG를 계산합니다. 경기별 OPS 평균을 내지 않습니다. MLBAM ID를 기준으로 매칭하며 누락값은 추정하지 않습니다.
- **OPS 축 직접 지정**: 체크박스로 활성화하고 최솟값·최댓값을 입력합니다. 범위 밖 점은 가장자리 표시와 실제 수치로 확인합니다.
- **기간 최고·최저**: 주간·월간 표시와 별개로 확보된 기간 내 전체 일별 누적 OPS에서 값과 날짜를 찾습니다. 기간은 표시 범위이며 시즌 누적의 시작점을 바꾸지 않습니다.
- **GIF/WebP 저장**: 기간, 6~12초, 5/10fps, 640×360/960×540, 반복 여부를 지정합니다. 별도 프로세스에서 생성하며 진행률·취소를 지원하고 실패·취소 시 기존 동명 파일을 보존합니다.
- **문서 예시**: README에 기존 `OPS_example.gif` 원본을 포함했습니다. 예시 선수 A/B의 가상 데이터이며 실제 성적이 아닙니다.

## 호환성과 사용

기존 fWAR, 선수/경기/홈/비교, QSettings, 데이터 위치 선택, DB·캐시를 유지합니다. 데이터 자동 이동·초기화는 없습니다. 설치·실행은 기존 `install.bat`, `run.bat`을 사용합니다. 기존 v1.7 검토용 ZIP을 v1.8 위에 다시 적용하지 마세요.

## 검증

- Python 3.12.14 / Linux Qt offscreen / 임시 사용자 프로필에서 검증했습니다.
- `python -m compileall -q .`: 통과.
- `python -m pytest -q`: **243개 통과**, 실패·건너뜀 없음. 기존 Matplotlib DejaVu Sans CJK 글리프 경고 19개.
- OPS 원시 카운트·ID·캐시·기간, 축 범위와 최고/최저, GIF/WebP 디코딩, 취소·실패 시 기존 파일 보존, UI 응답성 회귀 테스트를 포함합니다.
- README GIF는 전달 원본과 SHA-256이 일치합니다. `install.bat`과 `run.bat`은 변경하지 않았습니다.

## 남은 제한

- 목표는 Windows 11입니다. Linux Qt offscreen 검증이 Windows 설치·파일 선택창·취소·종료 실환경 검증을 대신하지 않습니다.
- OPS는 정규시즌 타격만 지원합니다. 포스트시즌·투수 피OPS는 포함하지 않습니다.
- WebP는 Pillow 지원 여부에 따릅니다. 고해상도 저장은 일시적으로 수백 MB의 메모리를 사용할 수 있습니다.
- GIF/WebP는 창 전체 녹화가 아닌 별도 차트 구성입니다. 선수 사진 대신 컬러 마커를 사용합니다.
- EXE·installer·GitHub Release·tag는 생성하지 않았습니다. 기존 패키징 준비의 제한은 유지됩니다.
