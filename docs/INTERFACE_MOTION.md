# 부드러운 인터랙션

앱 시작 시 `MotionManager`가 전체 Qt 앱의 입력 이벤트를 관찰합니다. 클릭 이벤트를 지연하거나 추가 발생시키지 않습니다.

- 버튼·툴 버튼: 호버, 80ms 눌림 강조, 160ms 복귀. 중간 입력은 현재 상태에서 이어서 처리합니다.
- 탭: 190ms OutCubic 선택 표시선 이동. 탭 내용은 즉시 표시하며 대형 차트 화면을 매번 캡처하지 않습니다.
- 일반 스크롤 영역: 마우스 휠 노치에 170ms 감속. 터치패드의 픽셀 델타 및 수정키 조합은 기본 Qt 동작을 사용합니다.
- 테마 전환: 220ms OutCubic. 연속 전환 시 이전 애니메이션을 중단합니다.
- 설정 → 화면 효과 줄이기: 저장 후 인터랙션 전환 및 테마 전환을 즉시 적용합니다. Qt가 제공하는 시스템 동작 줄이기 힌트도 확인합니다.
- 투명 오버레이는 클릭을 가로채지 않습니다. 비활성 버튼은 효과를 끄며, 키보드 포커스 표시는 기존 QSS를 유지합니다.

데모 그래프에 있는 단절은 예시 데이터의 결측을 표시한 것입니다. 수치가 없는 날짜를 채우거나 스플라인으로 연결하지 않습니다.
