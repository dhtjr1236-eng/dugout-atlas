# Dugout Atlas v1.40 — Settings와 3개 언어

## 설정 화면

상단 **설정 / Settings / 設定**에서 일반·데이터·진단정보를 관리합니다. 설정은 QSettings에 저장되어 다음 실행에서도 유지됩니다.

- 경기 자동갱신: 15–3,600초, 기본 30초.
- 선수 자동갱신: 60–3,600초, 기본 300초.
- 테마: Light / Dark. 기존 상단 테마 버튼과 같은 저장값을 사용합니다.
- 글자 크기: 80–160%. 화면 글꼴과 차트의 기본 글꼴 크기에 적용합니다.
- 알림: 즐겨찾기 팀의 득점·경기 상태 알림을 켜거나 끕니다.
- 언어: 영어·한국어·일본어 중 선택하고 저장하면 즉시 반영합니다.

## 기존 설명과 언어 전환

메뉴·버튼·패널·표 제목과 내장 지표 설명, 비교 툴팁, 즐겨찾기 안내, 기간 선택 설명 등에 번역문을 적용했습니다. 이미 열린 화면을 다시 번역하고, 이후 데이터 갱신 시에도 선택한 언어로 표시합니다. 기존 지표 설명의 영어·일본어 번역은 테스트로 확인합니다.

번역문은 앱에 포함됩니다. 외부 번역 서비스나 API 키가 필요하지 않습니다. 선수·팀 이름, 통계 약어 및 외부 제공처 원문은 유지하며, 새로 추가하는 UI 문구는 `config/translations.json`에 번역을 등록해야 합니다. 화면 글꼴은 Windows 한국어·일본어 글꼴과 Noto CJK 등을 폴백으로 사용합니다.

## 캐시와 데이터 위치

- **캐시 삭제:** DB의 조회 캐시와 다운로드 캐시만 삭제합니다. Python 캐시 모듈, 가져온 B-Ref 파일, 즐겨찾기를 보존합니다.
- **소스별 새로고침:** MLB / FanGraphs / Baseball-Reference / Savant를 선택하여 해당 캐시를 지웁니다. 설정을 닫으면 현재 경기와 선택한 선수를 재조회합니다. 다른 소스는 기존 캐시 정책을 적용합니다.
- **B-Ref:** 공식 로컬 파일을 우선하는 기존 동작과 403/429 차단 상태를 유지합니다. 새 WAR 원본 반영은 파일 가져오기를 이용합니다.
- **데이터 위치:** 현재 데이터 폴더 밖의 빈 폴더를 선택하면 기존 데이터를 복사하고 다음 실행부터 새 위치를 사용합니다. SQLite 백업 API를 사용하며 원래 폴더를 보존합니다. 대상에 기존 파일이 있거나 원본과 중첩되면 거부합니다.
- 진행 중인 조회가 있으면 데이터 관리 버튼을 비활성화합니다. Settings를 여는 동안 자동갱신을 일시 중지하고 닫을 때 설정한 간격으로 재개합니다.

## 진단정보

앱·OS·Python·의존성 버전과 소스별 DB 캐시 건수·마지막 저장 시각을 화면에서 확인하고 JSON으로 내보낼 수 있습니다. 개인 경로, 검색 기록, 로그, 자격 증명, 가져온 파일 내용은 포함하지 않습니다. 캐시 저장 시각은 제공처의 실제 데이터 갱신 시각과 다를 수 있습니다.

## 검증

`tests/test_settings_v140.py`에서 다음을 확인합니다.

- 설정 저장과 잘못된 값의 기본값·범위 처리
- 영어·한국어·일본어 즉시 전환과 기존 지표 설명 번역
- 소스별 캐시 삭제 시 다른 소스 데이터와 원본 파일 보존
- 잘못된 소스 이름에 대한 캐시 삭제 거부
- SQLite 데이터와 즐겨찾기 복사, 기존·중첩 대상 거부
- 진단정보에서 개인 경로 제외
- Settings 저장 후 실제 타이머 간격·테마 글자 크기·언어 적용

기존 회귀 테스트를 포함한 **72개 테스트가 로컬 오프스크린 Qt 환경에서 통과**했습니다. 컴파일, Ruff 실행 오류 검사와 Bandit 중간·높은 심각도 검사가 통과했고, 의존성 감사(pip-audit)에서 알려진 취약점이 발견되지 않았습니다. 설정 화면의 한국어·일본어 배치를 130% 글자 크기로 확인했습니다. Windows 네이티브 실행 확인은 이 검증에 포함되지 않습니다.
