# Dugout Atlas 비시즌 홈 사용 및 적용 안내

## 적용 범위

현재 소스 버전은 v1.7이다. 기존 유지보수 변경 위에 비시즌에도 사용할 수 있는 홈 탭을 추가했다. 경기/라인업/선수/비교/순위 탭은 유지한다. 사용자 DB·캐시·설정을 삭제하거나 이동하지 않는다.

## 사용 방법

1. 앱 시작 시 열리는 홈에서 '살펴볼 시즌'을 고른다. 다른 화면을 보다가 마지막 '홈' 탭으로 돌아올 수 있다.
2. '내 기록 보관함'은 선택 시즌의 로컬 player_stats에 저장된 선수 수·소스 키 수·캐시 항목 수와 마지막 저장 시각을 보여준다. 전체 MLB 선수 수나 최종 시즌 성적, 최신성 보증이 아니다. 값이 없으면 명확한 빈 상태를 보여준다.
3. 즐겨찾기 선수를 누르면 해당 MLBAM ID와 선택 시즌으로 기존 선수 분석을 연다. 즐겨찾기 추가/삭제는 기존 선수 화면에서 한다. 홈에 다시 들어오거나 '로컬 현황 새로고침'을 누르면 목록을 다시 읽는다.
4. '선수 탐색'은 선수 탭과 상단 검색 입력으로 이동한다. 검색한 선수를 선택하면 분석한다.
5. '선수 비교하기'는 기존 비교 화면을 연다. 홈에서 고른 시즌이 적용된다.
6. '시즌 레이스 다시 보기'는 별도 심화 비교 창의 Season Race 탭을 연다. 심화 비교 탭에서 선수 두 명을 먼저 골라야 레이스를 실행할 수 있다. 자료가 없는 경우 WAR를 추정하지 않는다.
7. '리그 순위 돌아보기'는 선택 시즌의 순위를 조회한다. 실제 조회는 기존 worker 경로에서 이루어진다.

왼쪽 경기 날짜와 홈의 분석 시즌은 별도다. 동일 날짜를 자동 갱신할 때 홈에서 고른 분석 시즌이 초기화되지 않도록 했다. 사용자가 경기 날짜를 다른 날짜로 바꾸면 기존처럼 해당 연도로 조회 기준이 바뀐다.

홈은 항상 사용할 수 있다. 단순히 하루 경기가 없다는 이유로 비시즌/시즌 종료라고 판정하지 않는다. 일정 확인 전/조회 중/경기 있음/경기 없음/조회 실패를 나눠 표시한다. 연결 실패는 오프라인 확정 판정이 아니며 연결 확인 안내를 보여준다. 홈의 로컬 현황 조회는 새 외부 API 요청을 만들지 않는다. 기존 경기 자동 갱신과 분석 버튼에 따른 조회는 유지된다.

## UI 및 접근성

EN/KO/JA, Light/Dark, 기존 Accent 체계를 사용한다. 좁은 홈 영역에서는 두 열 카드가 한 열로 바뀌고, 시즌 선택과 새로고침도 줄을 나눈다. 내용이 길면 세로 스크롤로 접근한다. 미구현 노트/예측/비교 저장 버튼은 추가하지 않았다.

## 덮어쓰기 패치 적용

v1.7 main 소스는 원본 v1.61(6a8eb57)부터의 유지보수와 홈 변경을 포함한다. 아래 payload 절차는 별도로 제공된 덮어쓰기 ZIP의 적용 방법이다. 기존 2026-10-04/05 ZIP은 당시 v1.61 표시의 작업본이므로 v1.7 위에 다시 적용하지 않는다. GitHub main ZIP을 받았다면 압축 내부 프로젝트 내용으로 업데이트하고, 직접 수정한 코드는 먼저 비교한다.

1. 앱을 완전히 종료한다.
2. 프로그램 폴더 전체와 별도로 지정한 데이터 폴더를 백업한다.
3. ZIP을 임시 폴더에 푼다.
4. payload **안의 내용**을 기존 main.py가 있는 폴더에 복사해 같은 이름의 파일만 바꾼다. 폴더는 합치며, cache/config/database 폴더 전체를 삭제하지 않는다.
5. 기존 run.bat으로 실행하고 홈·기존 선수 검색·즐겨찾기·테마를 확인한다.

paths.py 한 개만 복사하면 안 된다. 패치에 사용자 DB, 캐시 다운로드, 개인 설정은 포함하지 않았다. 문제가 있으면 종료 후 현재 폴더를 보관하고 백업 원본 폴더에서 실행한다. 패치 후 생긴 데이터는 따로 보존하고 DB끼리 무작정 덮어쓰지 않는다.

전체 소스 ZIP은 새 폴더에 풀어 install.bat 후 run.bat으로 실행한다. 기존 data_root가 없으면 새 폴더의 data/를 사용하므로 기존 기록이 자동으로 옮겨지지 않는다. 기존 사용자에게는 덮어쓰기 패치를 권장한다.

## 화면 예시와 검증 한계

전달한 PNG는 PyQt 앱을 실제 offscreen 실행해 캡처했다. 독립 임시 설정·예시 즐겨찾기·예시 캐시 개수를 사용했다. 화면의 숫자는 실제 선수 통계나 최신 MLB 조회 결과가 아니다. 네트워크 요청 없이 촬영했고 예시 데이터 표기를 넣었다.

Windows 11 EXE/설치 프로그램을 실행·빌드하지 않았다. Linux Qt offscreen 테스트와 시각 검수를 수행했다. 홈은 한국어가 정상 표시되도록 캡처 환경에 Noto CJK 폰트를 설치했다. 기존 Matplotlib 그래프 테스트의 DejaVu Sans CJK 경고는 별도 이슈로 남을 수 있다.

재현 명령:

```text
python -m compileall -q .
python -m pytest -q
python tools/preview_home.py --output preview-home
```

소스 실행의 기존 QSettings와 data_root는 유지하며, frozen 저장 정책 통일은 이전과 같이 준비 단계다. v1.7은 GitHub main 소스 업데이트로 제공하며, 별도 GitHub Release·EXE·installer는 생성하지 않는다.

최종 검증: compileall 통과, pytest 195개 통과(기존 대비 신규 12개), 실패/오류/skip 0, 기존 그래프 CJK 글리프 경고 19개. git diff --check 통과.
