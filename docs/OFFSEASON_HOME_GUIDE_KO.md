# Dugout Atlas 비시즌 홈 사용 및 적용 안내

## 적용 범위

현재 소스 버전은 v1.7이다. 기존 유지보수 변경 위에 비시즌에도 사용할 수 있는 홈 탭을 추가했다. 경기/라인업/선수/비교/순위 탭은 유지한다. 사용자 DB·캐시·설정을 삭제하거나 이동하지 않는다.

## 사용 방법

1. 앱 시작 시 열리는 홈에서 '살펴볼 시즌'을 고른다. 다른 화면을 보다가 마지막 '홈' 탭으로 돌아올 수 있다.
2. '내 기록 보관함'은 선택 시즌의 로컬 player_stats에 저장된 선수 수·소스 키 수·캐시 항목 수와 마지막 저장 시각을 보여준다. 전체 MLB 선수 수나 최종 시즌 성적, 최신성 보증이 아니다. 값이 없으면 명확한 빈 상태를 보여준다.
3. 즐겨찾기 선수를 누르면 해당 MLBAM ID와 선택 시즌으로 기존 선수 분석을 연다. 즐겨찾기 추가/삭제는 기존 선수 화면에서 한다. 홈에 다시 들어오거나 '로컬 현황 새로고침'을 누르면 목록을 다시 읽는다.
4. '선수 탐색'은 선수 탭과 상단 검색 입력으로 이동한다. 검색한 선수를 선택하면 분석한다.
5. '선수 비교하기'는 기존 비교 화면을 연다. 홈에서 고른 시즌이 적용된다.
6. '시즌 레이스 다시 보기'는 별도 심화 비교 창의 Season Race 탭을 연다. 심화 비교 탭에서 선수 두 명을 먼저 골라야 레이스를 실행할 수 있다. 자료가 없는 경우 WAR를 추정하지 않는다.
7. '리그 순위 돌아보기'는 선택 시즌의 순위를 조회한다. 실제 조회는 기존 worker 경로에서 이루어진다.

왼쪽 경기 날짜와 홈의 분석 시즌은 별도다. 동일 날짜를 자동 갱신할 때 홈에서 고른 분석 시즌이 초기화되지 않도록 했다. 사용자가 경기 날짜를 다른 날짜로 바꾸면 기존처럼 해당 연도로 조회 기준이 바뀐다.

홈은 항상 사용할 수 있다. 단순히 하루 경기가 없다는 이유로 비시즌/시즌 종료라고 판정하지 않는다. 일정 확인 전/조회 중/경기 있음/경기 없음/조회 실패를 나눠 표시한다. 연결 실패는 오프라인 확정 판정이 아니며 연결 확인 안내를 보여준다. 홈의 로컬 현황 조회는 새 외부 API 요청을 만들지 않는다. 기존 경기 자동 갱신과 분석 버튼에 따른 조회는 유지된다.

## UI 및 접근성

EN/KO/JA, Light/Dark, 기존 Accent 체계를 사용한다. 좁은 홈 영역에서는 두 열 카드가 한 열로 바뀌고, 시즌 선택과 새로고침도 줄을 나눈다. 내용이 길면 세로 스크롤로 접근한다. 미구현 노트/예측/비교 저장 버튼은 추가하지 않는다.
