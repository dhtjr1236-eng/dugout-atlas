# Neon HUD — 3단계

- Season Race의 차트 영역에 공통 HUD 프레임을 적용합니다.
- 두 선수의 선색은 `race_palette()`로 통일합니다. Gold의 경우 보조 선색을 보라색으로 바꿔 구분합니다.
- Neon 다크에서만 실제 기록선 아래에 제한된 글로우를 표시합니다. 라이트에서는 높은 대비를 유지합니다.
- 축에 포함된 결측 지점은 NaN으로 구분해 선을 끊습니다. 값이나 스플라인 보간으로 결측을 채우지 않습니다.
- PNG/JPEG는 기존 실제 화면 캡처 경로를 사용하므로 HUD 프레임과 현재 테마가 함께 저장됩니다.
- GIF/WebP는 별도 Pillow 렌더러를 유지하되 화면과 동일한 토큰·팔레트·다크 전용 글로우·코너 프레임을 사용합니다.
- 내보내기 스냅샷이 액센트를 보관하므로 저장 중 UI 테마를 변경해도 영상 색상이 바뀌지 않습니다.
- 기존 재생·취소·축 범위·출력 파일 보존 처리는 유지합니다. 화면과 영상은 해상도 및 정보 배치가 달라 픽셀 단위 복제본은 아닙니다.

```powershell
.\.venv\Scripts\python.exe tools/preview_hud_stage3.py --output output/neon-stage3
```

생성되는 레이스 화면과 GIF는 오프라인 예시 데이터입니다. 실제 선수 기록이 아닙니다.
